# Data credit risk

Unduh dataset **German Credit Data with Risk** dari Kaggle:
https://www.kaggle.com/datasets/kabure/german-credit-data-with-risk

Simpan file `german_credit_data.csv` di folder ini (`data/credit/german_credit_data.csv`).
Isinya 1.000 pemohon kredit dengan 9 fitur dan label `Risk` (good / bad).
