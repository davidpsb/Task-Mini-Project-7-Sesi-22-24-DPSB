# K05 — Skor Risiko dan Keputusan Kredit
Pasal 1: Model skor risiko menghitung probabilitas gagal bayar pemohon dari data aplikasi.
Pasal 2: Probabilitas di bawah 0,3 disetujui otomatis, 0,3 sampai 0,6 ditinjau analis kredit, dan di atas 0,6 ditolak.
Pasal 3: Model skor risiko dievaluasi ulang setiap 6 bulan atau segera setelah tim data mendeteksi drift.
